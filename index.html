About Spartan Orion Screener

How It Works

Spartan Orion Screener is a single-file market scanner for Binance Futures. Click Scan Market to pull live tick data from Orion Terminal’s public API, filter by activity and volatility, and surface the most active setups. Hover a row to open an instant chart preview backed by Binance candles.

Chart Preview

The preview uses a 1m chart by default and can overlay previous-candle S/R levels from 15m, 1h, 4h, and 1d (yesterday's high/low). Maximized view also shows VolUSD (volume x close) with its adaptive MA and extreme line. Toggle or resize the preview in Settings.

Use Anywhere

This is a standalone HTML tool. Use the Download HTML button (or grab it from the repo), then open it in your browser (no installation required). The hosted version is mainly for demo/testing. Install it as a PWA from GitHub Pages for app-like behavior.

Credits & Responsible Use

Data is provided by Orion Terminal’s public screener API and Binance Futures candles. Please use these sources responsibly, respect rate limits, and follow the providers’ terms of service.
